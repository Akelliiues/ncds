  สำนักงานสาธารณสุขอำเภอตาลสุม จังหวัดอุบลราชธานี

📦 วิธีการติดตั้งและเริ่มใช้งาน:
------------------------------------------------------------------
1. คลายไฟล์ .ZIP นี้ออกมาไว้ในโฟลเดอร์ใดก็ได้บนเครื่องคอมพิวเตอร์ (เช่น C:\NCDs_RedAlert)
2. ดับเบิ้ลคลิกไฟล์ "NCDs_RedAlert_Station.exe" เพื่อเริ่มโปรแกรม
3. ในการเปิดใช้งานครั้งแรก ระบบจะให้เลือก "รหัส รพ.สต. ของท่าน" และกดบันทึก
4. โปรแกรมจะทำงานเฝ้าระวังอยู่เบื้องหลังที่ System Tray (มุมขวาล่างของจอข้างนาฬิกา)
5. เมื่อ อสม. คัดกรองพบเคสวิกฤต (ความดันสูง/น้ำตาลสูง) ระบบจะส่งเสียงไซเรนและเด้งหน้าต่างเตือนทันที

🛡️ ข้อมูลความปลอดภัย:
------------------------------------------------------------------
โปรแกรมนี้เป็นซอฟต์แวร์ทางการแพทย์และสาธารณสุข พัฒนาขึ้นโดยเฉพาะสำหรับ
ระบบ NCDs Portal อำเภอตาลสุม ปลอดภัย 100% ไม่มีโฆษณาหรือมัลแวร์ใดๆ
หาก Windows SmartScreen แสดงข้อความเตือนในการเปิดครั้งแรก ให้กด "More info" แล้วเลือก "Run anyway" (ทำงานต่อไป)
